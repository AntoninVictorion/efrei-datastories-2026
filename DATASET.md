# Dataset used

- **Title:** Pathologies: number of patients by condition, sex, age group and territory
- **Publisher:** Caisse nationale de l'Assurance Maladie (CNAM)
- **Portal:** data.gouv.fr
- **Link:** https://www.data.gouv.fr/datasets/pathologies-effectif-de-patients-par-pathologie-sexe-classe-dage-et-territoire-departement-region
- **Licence:** ODbL (source must be cited; derived databases shared under the same conditions)
- **Coverage:** 2015-2024, updated 6 July 2026
- **Raw file:** 945 MB CSV, not included. Downloaded by `python scripts/download_data.py all`.
- **Included in the zip:** processed parquet tables in `data/processed/` (a few MB), enough to run the app.
